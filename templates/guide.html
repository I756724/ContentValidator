What It Does

UA Content Validator is a pre-translation validation tool for SAP User Assistance developers. It analyzes English content before it goes to German translation and identifies issues that would cause translator questions or errors.

The tool performs four types of analysis:

  • SAPterm Lookup – verifies terminology exists in the official SAP terminology database and shows the approved German translation
  • Fiori Guidelines Check – validates UI text against SAP Fiori UI Text Guidelines (element-specific rules)
  • German Translation Readiness – flags ambiguous compounds, length expansion risk, and terms with multiple German translations
  • AI Analysis – provides grammar checking, guideline-aligned suggestions, and German complexity rating
The tool validates against SAP Fiori UI Text Guidelines, SAP Style Guide for Technical Communication, SAPterm, SAP Wiki, and Help Portal. AI suggestions always reference the specific guideline they are based on.

Choose UI Text for any short text that appears in the SAP Fiori interface, or Text for documentation and longer content.

2

Select Element Type (UI Text only)

Choose the specific UI element from the dropdown. Each element type has different validation rules from the SAP Fiori UI Text Guidelines.

3

Enter Your Text

Paste or type the English text you want to validate in the main input field.

4

Add Context (Optional)

Provide additional information about the text — its purpose, UI location, or business scenario. This improves AI suggestion accuracy.

5

Click Validate

UI Text Validation

When validating UI text, the tool applies element-specific rules from the SAP Fiori UI Text Guidelines:

Element TypeKey Rules Applied
App TitleTransactional apps: start with verb + plural object. Analytical: noun-based. No jargon.
ButtonImperative verb form. Max 3 words. No articles. No "Click/Press".
ActionVerb + object. Title case. Can be longer than buttons (4–5 words).
TabTitle case. Noun phrase. 1–3 words. Count format: "Items (4)".
Section HeadingTitle case. Noun phrase. Don't overlap with parent section.
Field LabelTitle case. Noun phrase. No verbs, no articles. Colon is automatic.
Column HeaderTitle case. Singular if one entry per row. Slash with spaces for multiple values.
Status TextSentence case if long, title case if short. No ending period.
Message TextNo "successfully". No "(s)" for plural. Tell user what to do. No semicolons.
Facet TitleTitle case. Noun phrase. Can include count in parentheses.
Source: SAP Fiori UI Text Guidelines for SAP Fiori Apps

Text Validation

When validating general text (documentation, descriptions), the tool checks:

  • Compound nouns – flags chains of 3+ consecutive nouns (German reverses compound order)
  • Passive voice – German passive is structurally more complex
  • Vague pronouns – "This", "It", "That" at sentence start need clear antecedent (German pronouns have gender)
  • Sentence length – sentences over 25 words expand significantly in German
  • Terminology – business terms are checked against SAPterm for approved translations
  • Grammar – AI checks for subject-verb agreement, plural consistency, and ambiguity

Troubleshooting

"SAPterm: Service unavailable"

The SAPterm authentication cookie has expired. Re-authenticate using sap-auth-mcp with the SAPterm entry URL. Cookies typically last 24 hours.

AI returns "Unknown" complexity

The AI service did not respond. Check that the LLM proxy is running (local) or that the AI Core service binding is active (BTP). Try validating again.

No suggestions appear

If the AI section is empty, the AI service may be temporarily unavailable or the text is too short for meaningful analysis. Ensure at least 2–3 words are entered.

SAPterm shows "not found" for a known term

SAPterm uses exact matching by default. Check spelling and capitalization. The tool also searches for similar terms using "starts with" matching.

Validation is slow

The tool queries multiple services (SAPterm, Wiki, Help Portal, AI). Response time depends on network connectivity and AI service load. Typical response: 5–15 seconds.

Wiki search finds no results

Wiki authentication may have expired. Re-authenticate using sap-auth-mcp with the wiki entry URL. The tool will still function without wiki — AI and SAPterm results remain available.

For issues not covered here, contact the UA Content Validator team or raise a ticket in the project repository.
